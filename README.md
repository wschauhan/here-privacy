# Here — privacy & support site

Static pages published with GitHub Pages, used by the Here iPhone app for its
Privacy information and Support links.

- `index.html` — privacy policy → https://wschauhan.github.io/here-privacy/
- `support.html` — support page → https://wschauhan.github.io/here-privacy/support.html

## Publishing

1. Create a GitHub repository named `here-privacy` under `wschauhan`.
2. Copy the contents of this `site/` folder into the repository root.
3. In the repository: **Settings → Pages → Source: Deploy from a branch → `main` / `root`**.
4. The URLs above become live within a minute.

Keep the URLs in `Here/AppInfo.swift` in sync if the repository or account changes.
